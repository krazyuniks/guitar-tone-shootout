# Conversation UX (CLI Environment)
- User is in a CLI with limited screen real estate.
- One question at a time -- never dump pages then ask multiple questions.
- Context adjacent to question -- show ONLY the relevant snippet before asking.
- Build iteratively -- synthesise each answer into subsequent questions.
- Summarise periodically -- after 3-5 questions, recap decisions.
- No scroll-dependent layouts -- never assume user can see earlier content.
