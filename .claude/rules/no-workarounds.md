# No Workarounds Rule
- NEVER implement workarounds, stopgaps, or deviations from the plan.
- If the planned approach doesn't work: STOP, explain what isn't working and why, ask how to proceed, wait for direction.
- NEVER guess at architecture decisions, file locations, build processes, port configurations, or API contracts.
- Do not defer incomplete work unless scope explicitly allows it and user confirms.
- If plan doesn't match the codebase, point out the discrepancy and wait for clarification.
