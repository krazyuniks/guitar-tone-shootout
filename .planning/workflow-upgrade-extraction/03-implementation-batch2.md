**The ruff fix:**

`scripts/ruff-hook.sh` is a **pre-commit hook** — it runs automatically every time you `git commit`. It's registered in `.pre-commit-config.yaml` and executed by `prek` (Rust pre-commit runner).

**The bug:** The original used `grep -oP 'ruff==\K[0-9.]+'`:
- `-P` enables Perl-compatible regex (PCRE), which supports `\K` (reset match start — a lookbehind shorthand)
- macOS ships BSD grep, which **doesn't support `-P`** — it fails with `grep: invalid option -- P`
- Linux GNU grep supports `-P` fine

## Assistant Message #227 (line 729, 1006 chars, ts: 2026-02-19T11:31:01.175Z)

The original line:
```bash
ruff_version=$(grep -oP 'ruff==\K[0-9.]+' "$project_root/pyproject.toml")
```

The replacement:
```bash
ruff_version=$(sed -n 's/.*ruff==\([0-9.]*\).*/\1/p' "$project_root/pyproject.toml" | head -1)
```

Breaking it down:

- **`-n`** — suppress default output (don't print every line)
- **`s/…/…/p`** — substitute and print only if a match occurs
- **`.*ruff==`** — match anything up to and including `ruff==`
- **`\([0-9.]*\)`** — capture group: one or more digits and dots (the version number)
- **`.*`** — match the rest of the line
- **`\1`** — replace the entire line with just the captured version
- **`| head -1`** — in case multiple lines match, take only the first

So for a line like `"ruff==0.15.1",` it outputs `0.15.1`.

It's doing the same thing as `grep -oP 'ruff==\K[0-9.]+'` — the `\K` in Perl regex resets the match start so only the version part is output. The sed version achieves this by capturing the version in a group and replacing the whole line with it.
