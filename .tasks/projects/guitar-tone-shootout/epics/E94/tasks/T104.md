## Objective

Implement the outbound adapter that converts T3K staging records to GearSyncRecord format (from `libs/core/records/`) and publishes them to pgmq queues in gts_t3k_source. Transactional send: stage + enqueue in a single database transaction.

- [ ] `publish_model(model: T3KModelStaging)` converts to GearSyncRecord and enqueues to `gear_model_sync` queue
- [ ] Transactional: staging record update + pgmq enqueue in same database transaction
