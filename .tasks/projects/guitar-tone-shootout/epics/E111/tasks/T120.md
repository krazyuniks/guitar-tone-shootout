## Objective

Create Python CLI that wraps worker admin API HTTP calls. Uses source-agnostic command namespace. Register as `just admin` in justfile.

## Acceptance Criteria

- [x] `just admin source-status <source>` displays sync status, checkpoint, lag formatted as table
- [x] `just admin source-sync <source>` triggers manual sync, shows confirmation
- [x] `just admin jobs [--status=STATUS]` lists jobs in table format
- [x] `just admin job-health` shows overall health: Redis, DB, uptime, active jobs count
- [x] `just admin unlock-sync <source>` releases sync lock with confirmation
- [x] `just admin unlock-scheduler` releases scheduler lock with confirmation
- [x] CLI uses httpx to call `http://worker:8001` (Docker internal) or `http://localhost:8001` (host)
- [x] Connection errors produce clear error message ("Worker not reachable — is it running?")
- [x] `just admin` registered in justfile pointing to `scripts/gts-admin`
