## Objective

The worker entrypoint currently runs a Python `time.sleep(60)` loop as the pgmq consumer process (lines 151-158). Replace this with the real `GearSyncConsumer` that polls pgmq queues and processes gear sync messages.

## Acceptance Criteria

- [ ] Entrypoint spawns async process running `GearSyncConsumer.run()` with both core and T3K sessions
- [ ] Consumer polls `gear_pack_sync` and `gear_model_sync` queues in gts_t3k_source
- [ ] Consumer delegates to `GearMapperService` which writes to gts_core
- [ ] If consumer process exits, all processes stop (existing fail-fast behaviour preserved)
- [ ] After triggering sync: consumer processes messages from pgmq queues (not sleeping)
