## Objective

Replace the shootout-coupled `VideoComposer` protocol with a generic `VideoRenderer` port that supports any composition type. Add supporting value objects (`CompositionSpec`, `RenderStatus`) to decouple the core domain from shootout-specific video concerns, enabling the new Remotion-based video BC to use a clean submit/poll interface.
