## Objective

Implement the Python side of the video BC: FastAPI render endpoint (`POST /render`, `GET /render/{job_id}`, `GET /health`), gear image normalisation via Pillow, and domain-to-Remotion props serialisation. The Python layer handles the HTTP API contract, preprocesses images for compositions, and translates domain data into Remotion-compatible JSON props.
