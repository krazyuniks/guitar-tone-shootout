## Objective

Create the Dockerfile for the video BC (Node.js 20 + Chromium + Python/uv) and add a `video` service to docker-compose on the `jobs` profile. Remotion server-side rendering requires Node.js and Chromium. This runs as a separate service from the worker, communicating via HTTP.

## Acceptance Criteria

- [ ] `infrastructure/docker/Dockerfile.video` builds Node.js 20 + Chromium + Python/uv image
- [ ] `docker-compose.yml` has `video` service on `jobs` profile
- [ ] Video service mounts `libs/video/` source
- [ ] Video service exposes internal port (e.g. 8002)
- [ ] `docker compose --profile jobs up -d` starts video container
- [ ] Video container health check configured
