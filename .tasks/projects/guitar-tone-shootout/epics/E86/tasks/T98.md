## Objective

Extend the shootout creation wizard step 1 to allow selecting chains from a group. When a user picks a group, its generated chains are loaded and available for selection alongside individually created chains.

## Acceptance Criteria

- [x] Wizard step 1 shows two sections: "My Chains" and "From Groups"
- [x] "From Groups" section lists user's groups with chain count
- [x] Clicking a group expands to show its generated chains
- [x] User can select individual chains from the expanded group
- [x] Selected chains (from any source) appear in the selection summary
- [x] HTMX endpoint `GET /api/v1/html/shootout-create/group-chains/{group_id}` returns chain list for group
- [x] Minimum 2 chains required (validation preserved)
- [x] Integration test for wizard with group-based chain selection
- [x] `just check` passes
