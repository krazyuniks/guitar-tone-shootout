## Objective

Create a management command to bulk-import DI track audio files from a directory on disk into the database. The command reads audio files, extracts metadata, and creates records via `DITrackService`. Callable via a `just` recipe.

- [ ] Creates DITrack record for each file via `DITrackService.upload()`
- [ ] Skips duplicates (checksum match) without error
- [ ] Copies files to storage path (`/app/uploads/di-tracks/`)
- [ ] Reports summary: imported count, skipped count, error count
