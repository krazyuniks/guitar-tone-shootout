## Objective

Create a secure file serving service for DI tracks, IRs, and audio segments. Uses HMAC-signed URLs with expiration to prevent unauthorized access. Validates file ownership and prevents path traversal attacks.

## Acceptance Criteria

- [ ] `AssetService` with `generate_signed_url(file_path, user_id, expires_in)` method
- [ ] HMAC signature using `SECRET_KEY`, includes file path + user ID + expiry timestamp
- [ ] `GET /api/v1/files/{signature}` streams file with correct Content-Type
- [ ] Signature validation: rejects expired, tampered, or invalid signatures
- [ ] Ownership validation: file must belong to requesting user (or be public)
- [ ] Path traversal prevention: reject `..`, absolute paths, symlinks outside upload dir
- [ ] Supports streaming for large audio files (Range header support)
- [ ] Returns 404 for invalid/expired signatures (not 403 — no existence leaking)
- [ ] `just check` passes
