## Objective

Create an IR (Impulse Response) upload endpoint for community-contributed IRs. Uploading an IR creates a `Gear` entity with `source="community"` and an associated `GearModel` containing the IR file.

## Acceptance Criteria

- [ ] `POST /api/v1/irs/upload` accepts multipart file upload
- [ ] Accepts metadata: name, description, gear_type (defaults to "ir")
- [ ] Creates `Gear` with `source="community"`, `gear_type="ir"`
- [ ] Creates `GearModel` linked to the Gear, with IR file path
- [ ] File stored in upload directory with safe filename
- [ ] Validates file format (WAV/IR formats)
- [ ] Duplicate detection via checksum
- [ ] Returns created Gear + GearModel in response
- [ ] Requires `CurrentUser` authentication
- [ ] `just check` passes
