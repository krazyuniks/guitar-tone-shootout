## Objective

Fix the mismatch between the DI track upload form in the frontend and the API endpoint. The frontend posts to the wrong URL with wrong field names.

## Known Bugs

1. **URL mismatch:** Frontend `hx-post="/api/v1/di-tracks/upload"` → API listens on `POST /api/v1/di-tracks`
2. **Field name `title`:** Frontend `name="title"` → API expects `name` parameter
3. **Field name `pickups`:** Frontend `name="pickups"` → API expects `pickup` parameter
4. **Extra field `tuning`:** Frontend has `tuning` field not accepted by API — decide: add to API or remove from form

## Acceptance Criteria
