## Objective

Create a dynamic `sitemap.xml` endpoint that lists all public pages for search engine indexing. Includes static pages (homepage, about, gear browse), public shootouts, and gear detail pages.

## Acceptance Criteria

- [ ] `GET /sitemap.xml` returns valid XML sitemap
- [ ] Includes static pages: `/`, `/about`, `/gear`, `/shootouts`
- [ ] Includes public gear detail pages: `/gear/{slug}`
- [ ] Includes public shootout pages: `/shootouts/{id}`
- [ ] Uses `PUBLIC_URL` env var for absolute URLs
- [ ] Includes `lastmod`, `changefreq`, `priority` attributes
- [ ] Response has `Content-Type: application/xml`
- [ ] No authentication required
- [ ] `just check` passes
