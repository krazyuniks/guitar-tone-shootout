## Objective

Create FastAPI exception handlers for all exception types. Implement content negotiation so API routes (`/api/v1/*`) return JSON error responses while page routes return HTML error pages. Sanitise error details in production (strip stack traces, internal paths).

## Acceptance Criteria

- [ ] Handler for `AppException` — returns structured JSON or HTML based on route/Accept header
- [ ] Handler for `HTTPException` — wraps in consistent format
- [ ] Handler for `RequestValidationError` — returns 422 with field-level errors
- [ ] Handler for `SQLAlchemyError` — returns 500, logs full error, sanitises response
- [ ] Handler for unhandled exceptions — returns 500, logs full error, sanitises response
- [ ] Content negotiation: `/api/v1/*` routes → JSON; page routes → HTML error page
- [ ] Production sanitisation: no stack traces, no internal paths in responses
- [ ] Development mode: include stack traces and details
- [ ] All handlers mounted in `main.py`
- [ ] `just check` passes
