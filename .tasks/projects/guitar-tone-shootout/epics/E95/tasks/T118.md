## Objective

Create the notification system: ORM model, service layer, and API endpoints. Notifications are simple in-app messages (not email/push). They support queue, get unread, mark read, mark all read.

## Acceptance Criteria

- [ ] `UserNotification` ORM model with: id, user_id, type, title, message, read_at, created_at
- [ ] Alembic migration for user_notifications table
- [ ] `NotificationService` with: create, get_unread, get_all, mark_read, mark_all_read
- [ ] `GET /api/v1/notifications` — list user's notifications (unread first, paginated)
- [ ] `PUT /api/v1/notifications/{id}/read` — mark single notification as read
- [ ] `PUT /api/v1/notifications/read-all` — mark all as read
- [ ] All endpoints require `CurrentUser` authentication
- [ ] Ownership check: users can only access their own notifications
- [ ] `just check` passes
