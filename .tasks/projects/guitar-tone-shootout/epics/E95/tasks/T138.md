## Objective

Create CRUD API endpoints for shootout comments. Comments can be created, listed, and deleted. Only the comment author can delete their comments. Comments are listed in chronological order.

## Acceptance Criteria

- [ ] `ShootoutCommentService` with create, list_by_shootout, delete methods
- [ ] `ShootoutCommentRepository` with standard query patterns (joinedload for user)
- [ ] `POST /api/v1/shootouts/{id}/comments` — create comment (body: `{"content": "..."}`)
- [ ] `GET /api/v1/shootouts/{id}/comments` — list comments for shootout (paginated, newest first)
- [ ] `DELETE /api/v1/shootouts/{id}/comments/{comment_id}` — delete comment (author only)
- [ ] Shootout must exist (404 if not)
- [ ] Content validated: not empty, max 2000 chars
- [ ] Response includes comment author info (username, avatar)
- [ ] All endpoints require `CurrentUser` authentication
- [ ] Pydantic schemas for request/response
- [ ] `just check` passes
