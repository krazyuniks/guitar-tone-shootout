## Objective

Implement graceful shutdown for the webapp. On SIGTERM/SIGINT, stop accepting new requests, return 503 during drain period, wait for in-flight requests to complete, then exit cleanly.

## Acceptance Criteria

- [ ] Signal handlers registered for SIGTERM and SIGINT
- [ ] On shutdown signal: health endpoint returns 503 (nginx stops routing)
- [ ] In-flight requests allowed to complete (configurable drain timeout, default 30s)
- [ ] New requests during drain receive 503 Service Unavailable
- [ ] Clean database connection pool shutdown
- [ ] Shutdown logged with timing info
- [ ] Works with uvicorn's built-in signal handling (lifespan events)
- [ ] `just check` passes
