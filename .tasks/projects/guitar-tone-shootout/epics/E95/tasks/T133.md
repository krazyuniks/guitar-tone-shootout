## Objective

Create a read-only API endpoint that lists built-in processor block types with their parameter definitions. The `BlockTypeRegistry` service already exists with registered block type definitions.

## Acceptance Criteria

- [ ] `GET /api/v1/block-types` returns list of all registered block types
- [ ] Each block type includes: name, description, category, parameters with types/ranges/defaults
- [ ] Response is cacheable (block types are static)
- [ ] No authentication required (public reference data)
- [ ] Pydantic schema for response
- [ ] `just check` passes
