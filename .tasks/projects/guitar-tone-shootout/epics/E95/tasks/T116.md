## Objective

Create custom error pages for the application. Astro-built 404 and 500 pages for webapp errors. Static nginx error pages for 502 (bad gateway), 503 (service unavailable), 504 (gateway timeout) that display when webapp is down.

## Acceptance Criteria

- [ ] 404 page renders with GTS branding, navigation, "page not found" message
- [ ] 500 page renders with GTS branding, "something went wrong" message
- [ ] 404/500 pages built by Astro, output to `frontend/astro/dist/`
- [ ] Exception handlers from T115 serve these pages for HTML requests
- [ ] nginx serves static 502/503/504 pages when webapp is unreachable
- [ ] Error pages have `data-testid` attributes for testing
- [ ] `just build-astro` succeeds
- [ ] `just check` passes

## Scope

**Create/Modify:**
- `frontend/astro/src/pages/404.astro` or `404.html.ts` — custom 404 page
- `frontend/astro/src/pages/500.astro` or `500.html.ts` — custom 500 page
- `infrastructure/nginx/error-pages/` — static 502, 503, 504 HTML
- `infrastructure/nginx/nginx.conf.template` — wire nginx error pages

**Forbidden (test immutability):**
- `**/*.test.ts`
- `**/*.test.tsx`
