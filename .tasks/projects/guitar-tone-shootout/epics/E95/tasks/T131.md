## Objective

Create a Tag CRUD API. Tags are user-created labels for organising gear, chains, and shootouts. Tag names are lowercase-normalised and unique per user.

## Acceptance Criteria

- [ ] `TagService` with create, get_by_user, delete methods
- [ ] Tag names normalised to lowercase on create
- [ ] Duplicate tag names rejected (per user) with ConflictError
- [ ] `GET /api/v1/tags` — list current user's tags
- [ ] `POST /api/v1/tags` — create tag (body: `{"name": "..."}`)
- [ ] `DELETE /api/v1/tags/{id}` — delete tag (ownership check)
- [ ] Pydantic schemas for request/response
- [ ] All endpoints require `CurrentUser` authentication
- [ ] `just check` passes
